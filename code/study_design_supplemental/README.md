# Study Design Supplemental Scripts

These scripts are retained for provenance and sensitivity checks only. They are not part of the main analysis pipeline.

The main pipeline uses:

- `../5_add_study_design_and_topics.py`
- `../../data/analysis/analysis_dataset_enriched_v2.csv`

The archived variants in this directory generated alternative study-design outputs named `analysis_dataset_enriched_v2b.csv` through `analysis_dataset_enriched_v2f.csv` during classifier development. In sum, they didn't improve classification.
